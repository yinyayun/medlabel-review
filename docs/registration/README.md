## 重新生成

以下命令在项目根目录执行。已提供生成好的 Word/PDF，正常使用无需运行这些命令。

```bash
python -m pip install -r requirements-docs.txt

# 可选：重新截取真实界面，使用独立临时数据库
python -m playwright install chromium
python scripts/capture_registration_screens.py
# 已安装系统 Chromium 时也可指定：
# python scripts/capture_registration_screens.py --browser-path /usr/bin/chromium

# 从固定代码基线与 Markdown 生成 Word、源码清单
python scripts/build_registration_docs.py

# 需要另行安装 LibreOffice；中文排版使用 Noto Sans CJK SC 字体
soffice --headless --convert-to pdf --outdir docs/registration/pdf docs/registration/word/*.docx

# 检查生成材料并更新文档校验清单
python scripts/verify_registration_docs.py
```

生成工具要求本地 Git 历史含固定代码基线，并核对当前运行源码与基线一致。修改业务代码后，应先确定新的登记版本、更新编排工具中的基线与相关文档，再重新生成整套材料。

办理时以[中国版权保护中心](https://www.ccopyright.com.cn/)的最新要求为准。材料选取的基本依据见[国家版权局《计算机软件著作权登记办法》](https://www.ncac.gov.cn/xxfb/flfg/bmgz/202410/t20241015_869486.html)。本包提供技术文档和填报参考，不代替正式申请、权属确认或签章。
