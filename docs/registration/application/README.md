# V1.0 个人申请准备资料（申报条件待核实）

软件名称：**药品说明书版本比对与变更审核系统 V1.0**。

**[下载完整材料包（ZIP）](medlabel-review-copyright-application-v1.0.zip)**

本包按自然人、本人自行申请整理，包含已审查的技术文档及填报参考。**当前不能作为“仅补个人信息即可提交”的定稿。** 本项目代码与文档使用过 AI；除姓名、权属和日期等待填信息外，还必须先核对当前官方申报声明与实际开发经历是否相容。

## 先确认申报条件

2026-03-15 中国版权保护中心公告确认更换申请表。深圳市软件行业协会公布的新旧表对照列出了未使用 AI 编写代码、撰写文档或生成登记申请材料的声明，以及主要功能 500—1300 字要求。官方公告本身没有逐项刊出这些条文；目前未取得申请人登录系统后生成的当前签章页及针对本项目的适用答复。

请先核对官方系统当次声明，并向登记机构如实说明本项目 AI 参与范围、确认办理口径；若声明与事实不符，不应签署。润色、人工复核或检测分数变化不能把已有 AI 参与变成“未使用 AI”。现有材料保留为技术资料及填报参考，功能描述已按上述字数范围扩充，并不表示申报条件已经满足。

核对依据：[官方换表公告](https://www.ccopyright.com.cn/index.php?optionid=999&method=view&optionid=999&auto_id=1524)、[协会公布的新旧表对照](https://www.ssia.org.cn/page59?article_id=2588)。官方申请表及签章页仍须由办理系统生成，身份与权属证明由本人按真实情况提供。

## 申请字段中待补填或核实的内容

| 位置 | 需要填写或确认 |
| --- | --- |
| 当前官方签章页及登记机构答复 | AI 使用声明对本项目的适用口径；这是前置待办，不是修改姓名能解决的事项 |
| 说明书标题区、基本信息表及 Word 文件属性 | 本人身份证明上的完整姓名；保持署名一致 |
| 申请信息填写参考第 1 节 | 软件简称（没有则按表单规则留空）、软件作品说明（原创或修改） |
| 申请信息填写参考第 3 节 | 实际开发硬件环境；按事实补充办理表单要求的设备、系统或工具信息 |
| 申请信息填写参考第 4 节 | 姓名、国籍、开发方式、权利取得方式与范围、合作或职务等关系、实际开发完成日期 |
| 申请信息填写参考第 5 节 | 实际发表状态、首次发表日期及地点；不能仅凭仓库现在私有就填写未发表 |
| 官方办理系统 | 证件号码、联系信息、实名认证、身份证明、本人签名及适用证明材料 |

申请人类型已经确定为“自然人（个人）”，办理方式为“本人自行办理”。这不自动证明单独开发、原始取得、全部权利或没有职务关系。未确认的事实保持待填，不代为推定。

## 使用步骤

1. 先阅读《申请信息填写参考》第 0 节，核对当次官方声明并如实确认适用口径。下载文件可用于准备和咨询，不代表可以直接提交。
2. 在本地编辑 Word，完成《申请信息填写参考》中待填字段，再将拟提交说明书的署名统一。
3. 在拟提交的 Word 中搜索“待申请人填写”“待申请人确认”“待申请人核实”“申请信息待确认”；处理适用的提示和标题区状态文字，并检查文档属性中的作者。不要只修改填报参考而遗漏说明书。检查记录可留作自查，不必删除其中描述待办的历史文字；不得删除真实 AI 使用记录以制造未使用 AI 的表象。
4. 保持技术能力、源代码与软件版本描述一致。所有编辑过、拟提交的 Word 均应重新导出 PDF，再核对页码、表格和截图。
5. 在申报条件已如实核实后，按官方系统要求准备源程序鉴别材料，以及设计说明书或操作说明书中的一种；图表页和源程序计行等版式以办理要求或补正通知为准。
6. 在官方系统完成实名、填写申请信息、提交对应身份证明，下载系统生成的签章页，确认声明与事实相符后按要求本人签名并上传。如存在合作、委托、职务或继受关系，提供对应证明。本人自行办理不预设代理委托书或学校内部审批件。
7. 保留最终提交文件及受理记录。身份证件、签名和含个人信息的材料自行保管，不回传代码仓库。
