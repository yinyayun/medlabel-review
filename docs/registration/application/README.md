# V1.0 个人自行申请材料

软件名称：**药品说明书版本比对与变更审核系统 V1.0**。

**[下载完整材料包（ZIP）](medlabel-review-copyright-application-v1.0.zip)**

本包按自然人、本人自行申请整理，包含已审查的技术文档及填报参考。技术正文已经编制完成；申请人的姓名、权属、日期等事实仍需补填或确认。官方申请表及签章页须在办理系统中生成，身份证明及适用权属证明须由本人提供，因此不能仅改姓名就直接提交整包。

## 包内文件

压缩包共 11 个文件：一份使用说明和以下三个目录。Word 用于编辑，PDF 用于查看及补填后重新导出对照；不必把同一文档的 Word、PDF 都作为申请附件上传。

| 目录 | 文件 | 用途 |
| --- | --- | --- |
| 01_申请用技术材料 | 软件设计说明书.docx / .pdf（15 页） | 主要技术正文，说明背景、问题、设计、算法及案例；作为文档鉴别材料的候选 |
| 01_申请用技术材料 | 源程序鉴别材料.docx / .pdf（60 页） | 固定代码版本的前、后连续页段 |
| 02_备用操作说明 | 用户操作说明书.docx / .pdf（16 页） | 含实际操作截图；可按办理要求替代设计说明书作为文档鉴别材料 |
| 03_填报与检查 | 申请信息填写参考.docx（4 页） | 技术字段已写好，申请事实待填写；不是官方申请表 |
| 03_填报与检查 | 提交材料核对单.pdf（3 页） | 提交前逐项检查 |
| 03_填报与检查 | 源程序编排说明.pdf（2 页） | 解释代码来源、统计口径与页段选取，供核对 |
| 03_填报与检查 | 内容审查与提交待办.pdf（3 页） | 已修订问题、核验范围与尚未完成事项，供自查 |

以上页数对应包内 PDF；编辑 Word 后应重新检查实际页数。设计说明书与操作说明书一般选择一种作为文档鉴别材料。填报参考和检查记录供申请人使用，不应当作全部必须上传的附件。

## 只需补填或核实的内容

| 位置 | 需要填写或确认 |
| --- | --- |
| 说明书标题区、基本信息表及 Word 文件属性 | 本人身份证明上的完整姓名；保持署名一致 |
| 申请信息填写参考第 1 节 | 软件简称（没有则按表单规则留空）、软件作品说明（原创或修改） |
| 申请信息填写参考第 3 节 | 实际开发硬件环境；按事实补充办理表单要求的设备、系统或工具信息 |
| 申请信息填写参考第 4 节 | 姓名、国籍、开发方式、权利取得方式与范围、合作或职务等关系、实际开发完成日期 |
| 申请信息填写参考第 5 节 | 实际发表状态、首次发表日期及地点；不能仅凭仓库现在私有就填写未发表 |
| 官方办理系统 | 证件号码、联系信息、实名认证、身份证明、本人签名及适用证明材料 |

申请人类型已经确定为“自然人（个人）”，办理方式为“本人自行办理”。这不自动证明单独开发、原始取得、全部权利或没有职务关系。未确认的事实保持待填，不代为推定。

## 使用步骤

1. 下载并解压，在本地编辑 Word。先完成《申请信息填写参考》中待填字段，再将拟提交说明书的署名统一。
2. 在拟提交的 Word 中搜索“待申请人填写”“待申请人确认”“待申请人核实”“申请信息待确认”；处理适用的提示和标题区状态文字，并检查文档属性中的作者。不要只修改填报参考而遗漏说明书。检查记录可留作自查，不必删除其中描述待办的历史文字。
3. 不改变已经核对的技术能力、源代码或软件版本。若只补填个人与申请事实，无需重写背景、设计或操作步骤。所有编辑过、拟提交的 Word 均应重新导出 PDF，再核对页码、表格和截图。
4. 按官方系统要求准备源程序鉴别材料，以及设计说明书或操作说明书中的一种；图表页和源程序计行等版式以办理要求或补正通知为准。
5. 在官方系统完成实名、填写申请信息、提交对应身份证明，下载系统生成的签章页，按要求本人签名并上传。如存在合作、委托、职务或继受关系，提供对应证明。本人自行办理不预设代理委托书或学校内部审批件。
6. 保留最终提交文件及受理记录。身份证件、签名和含个人信息的材料自行保管，不回传代码仓库。
