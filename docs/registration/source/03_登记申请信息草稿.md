### 2. 可直接复制的功能描述

以下字数按 Python 字符数统计，包含标点、英文字母和数字。该字数仅用于控制草稿长度；录入时应以办理系统实际提示为准。

#### 2.1 开发目的

辅助药学人员整理说明书版本、定位文本变化并留存人工审核记录。

字符数：30。

#### 2.2 面向领域／行业

医药信息管理、药学资料审核。

#### 2.3 主要功能

建立药品档案并导入纯文字PDF、DOCX、TXT或粘贴文本，保存版本日期、来源和原始文件；自动识别章节并支持人工校正，对比同一药品新旧版本的新增、删除及修改内容，提示数字、单位和重点章节变化；记录确认、忽略及复核意见，导出HTML、CSV、JSON报告，查询操作记录。

字符数：134。

#### 2.4 技术特点

采用Python与FastAPI构建本地服务，SQLite存储业务数据；按规范化章节标题对齐并计算字符差异，保留文件SHA-256及原文位置，通过版本锁定、事务和修订号校验维护审核一致性。

字符数：94。
