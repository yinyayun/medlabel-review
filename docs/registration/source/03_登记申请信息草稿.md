### 2. 软件功能填报参考

以下字数按 Python 字符数统计，包含标点、英文字母和数字。主要功能参考文本按上述新表对照的 500—1300 字范围准备；实际录入仍以官方系统当次字段和计数提示为准，并以第 0 节申报条件已核实为前提。

#### 2.1 开发目的

辅助药学人员整理说明书版本、定位文本变化并留存人工审核记录。

字符数：30。

#### 2.2 面向领域／行业

医药信息管理、药学资料审核。

#### 2.3 主要功能

本软件用于药品说明书多版本资料的整理、文本差异核对和人工复核记录，面向药学资料整理、说明书审核及教学演示场景，将版本归档、章节比对、意见保存和报告导出组织在同一流程中。使用者可建立药品档案，填写名称、厂家、规格、批准文号及备注，在档案下分别导入旧版和新版说明书，记录版本名称、日期与资料来源。支持TXT、DOCX、纯文字且不含图片的PDF文件及粘贴文本；导入后保存原始文件、提取原文、文件SHA-256摘要和章节结构，供使用者查看原文、下载原件并核查输入内容。系统按标题规范化和明确的别名规则自动识别章节，保留重复标题及其出现次序；在版本尚未参与比对时，使用者可以人工添加、删除或修改章节，校正操作不改写原始文件与提取原文。创建比对时，程序检查所选版本是否属于同一药品、版本编号是否不同以及日期顺序是否符合要求，按规范化标题和同名章节出现次序配对，分别列出新增、删除和修改内容，并统计未变化章节。审核界面并列显示旧版与新版正文，突出字符增删，提示章节重排、重复标题和需人工核查的长章节。程序依据固定重点章节、数字序列及单位序列的变化设置关注标记，便于安排复核顺序；这些提示不进行剂量换算或医学语义判断，不构成临床风险评级或监管结论。每项变化初始为待复核，使用者可确认、忽略或恢复待复核，并填写审核意见；忽略操作要求填写原因。系统保存操作者显示名、处理时间和修订号，根据差异状态汇总任务进度；旧窗口提交的修订号与当前记录不一致时拒绝覆盖，提示重新核对。已被比对引用的版本章节禁止继续修改，更正资料时需导入新版本并另建比对，以保留原任务依据。使用者可按审核状态及关注级别筛选差异，在审核过程中或完成后导出HTML、CSV、JSON报告，报告反映导出时点的版本来源、变化内容和人工处理状态，并可查询近期档案建立、版本导入、章节校正、比对创建及审核更新等操作记录。软件采用本地浏览器界面、Python与FastAPI服务、SQLite数据库及本地附件目录，按单机单个可信操作者使用设计；依赖安装完成后，资料处理不依赖外部大模型服务。不提供OCR、多人账户认证、电子签名、处方生成或药品监管数据库联网核验，输入提取结果和复核结论均由使用者结合原始资料确认。

字符数：923。

#### 2.4 技术特点

采用Python与FastAPI构建本地服务，SQLite存储业务数据；按规范化章节标题对齐并计算字符差异，保留文件SHA-256及原文位置，通过版本锁定、事务和修订号校验维护审核一致性。

字符数：94。
