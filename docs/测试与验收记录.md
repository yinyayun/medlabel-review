## 自动测试

`python -m pytest -q`：**51 项通过**。覆盖：

- UTF-8 / GB18030 TXT，纯文字 PDF，DOCX 正文、表格、页眉页脚。
- 含扫描图片及可提取页码的 PDF、嵌套图片和内联图片的拒绝路径。
- 重复标题、章节别名、章节重排、数字小数与单位变化、否定词变化。
- 原始文件 SHA-256 和原文下载，章节校正与比对引用锁定。
- 无变化版本、跨药品比对拒绝、日期顺序校验。
- 审核确认、忽略原因、恢复待复核、过期修订冲突及日志保留。
- HTML 转义、CSV 公式防护及中文编码、JSON 导出。
- 同源与本地主机限制，数据库重新打开及演示数据幂等性。

当前 Starlette 对测试工具 httpx 提示弃用警告；不影响本次测试通过。未来更新依赖时应再次验证兼容性。

## 结论范围

以上结果验证选定测试样例和操作路径，不代表可以正确解析所有现实药品说明书，也不是临床或监管认证。复杂排版、文档内容完整性和重点提示仍需人工对照原文件复核。V1.0 不提供 OCR、真实用户认证、电子签名或正式监管系统对接。
